--- PATCH FOR PPO OBSERVATION NORMALIZATION ---
File: rl_tools_adapter.cpp (in learning_to_fly_controller firmware)

PROBLEM:
========
PPO policies are trained with normalized observations (mean=0, std=1), but the
firmware feeds raw observations directly to the actor network. This causes
PPO policies to produce incorrect actions, resulting in unstable flight.

ROOT CAUSE:
===========
The PPO checkpoint exports normalization parameters in `actor.h`:
  - rl_tools::checkpoint::observation_normalizer::mean[146]
  - rl_tools::checkpoint::observation_normalizer::std_inv[146]
  - rl_tools::checkpoint::observation_normalizer::normalize(float* obs)

But rl_tools_control() in rl_tools_adapter.cpp never calls normalize().

MINIMAL FIX:
============
In rl_tools_adapter.cpp, modify the rl_tools_control() function.

BEFORE (around line 105-115):
-----------------------------
void rl_tools_control(float* state, float* actions){
    rlt::MatrixDynamic<rlt::matrix::Specification<T, TI, 1, 13, 
        rlt::matrix::layouts::RowMajorAlignment<TI, 1>>> state_matrix = {(T*)state};
    auto state_rotation_matrix_input = rlt::view(device, input, 
        rlt::matrix::ViewSpec<1, 18>{}, 0, 0);
    observe_rotation_matrix(state_matrix, state_rotation_matrix_input);
    
    // ... action history code ...
    
    rlt::MatrixDynamic<rlt::matrix::Specification<T, TI, 1, ACTOR_TYPE::SPEC::OUTPUT_DIM, 
        rlt::matrix::layouts::RowMajorAlignment<TI, 1>>> output = {(T*)actions};
    rlt::evaluate(device, rlt::checkpoint::actor::model, input, output, buffers);


AFTER (add normalization before evaluate):
------------------------------------------
void rl_tools_control(float* state, float* actions){
    rlt::MatrixDynamic<rlt::matrix::Specification<T, TI, 1, 13, 
        rlt::matrix::layouts::RowMajorAlignment<TI, 1>>> state_matrix = {(T*)state};
    auto state_rotation_matrix_input = rlt::view(device, input, 
        rlt::matrix::ViewSpec<1, 18>{}, 0, 0);
    observe_rotation_matrix(state_matrix, state_rotation_matrix_input);
    
    // ... action history code ...
    
    // ========================================================================
    // PPO FIX: Apply observation normalization before inference
    // ========================================================================
#ifdef RL_TOOLS_PPO
    {
        // Extract input data, normalize, write back
        T input_buffer[ACTOR_TYPE::SPEC::INPUT_DIM];
        for (TI i = 0; i < ACTOR_TYPE::SPEC::INPUT_DIM; i++) {
            input_buffer[i] = rlt::get(input, 0, i);
        }
        rlt::checkpoint::observation_normalizer::normalize(input_buffer);
        for (TI i = 0; i < ACTOR_TYPE::SPEC::INPUT_DIM; i++) {
            rlt::set(input, 0, i, input_buffer[i]);
        }
    }
#endif
    // ========================================================================
    
    rlt::MatrixDynamic<rlt::matrix::Specification<T, TI, 1, ACTOR_TYPE::SPEC::OUTPUT_DIM, 
        rlt::matrix::layouts::RowMajorAlignment<TI, 1>>> output = {(T*)actions};
    rlt::evaluate(device, rlt::checkpoint::actor::model, input, output, buffers);


BUILD INSTRUCTIONS:
===================
When building PPO firmware, add -DRL_TOOLS_PPO to CXXFLAGS:

Option 1: Modify CMakeLists.txt or Makefile:
  target_compile_definitions(your_target PRIVATE RL_TOOLS_PPO)

Option 2: Add to build command:
  make CXXFLAGS="-DRL_TOOLS_PPO"

Option 3: Modify Dockerfile_build_firmware to add the define when building PPO.
